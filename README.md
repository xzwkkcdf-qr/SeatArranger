## 项目简介

座位编排是一个无需安装、可直接在浏览器中使用的班级座位表工具。名单与班级设置保存在当前浏览器中，适合日常排座、打印和导出。

## 主要功能

- 导入 Excel、CSV 学生名单，或手动维护学生信息。
- 按学号、姓名或随机方式安排座位，并支持拖拽调整。
- 设置行数、列数和一键中央走道。
- 标记特殊座位、固定学生位置，并保存多个班级配置。
- 导出 PNG、PDF 或直接打印座位表。

## 使用方式

1. 双击 `start.bat` 启动本地服务。
2. 浏览器打开显示的本地地址。
3. 也可直接用浏览器打开 `index.html`。

## 项目结构

- `index.html`：页面结构与本地库加载。
- `css/style.css`：书院风格的响应式界面样式。
- `js/app.js`：名单、排座、存储和导出逻辑。
- `js/layout.js`：行列布局与中央走道计算。
- `libs/`：本地 Excel 与导出所需依赖。
