# README 与布局简化设计

## 目标

为座位表编排工具新增中文 README，使使用者在打开仓库时首先看到使用限制：项目免费、不得用于商业用途，转载时必须注明原始出处；同时将座位布局简化为行列式，并增加智能中间走道。

## 文档结构

1. 使用与转载声明：置于 README 的第一项内容，使用醒目标题和三条明确规则。
2. 项目简介：说明这是一个本地运行的座位表编排工具。
3. 主要功能：概述名单导入、座位布局、排座与导出能力。
4. 使用方式：说明双击 `start.bat` 或用浏览器打开 `index.html`。
5. 项目结构：列出入口页面、样式、脚本及本地依赖库。

## 布局简化

1. 移除布局下拉框、小组人数控件，以及小组式和圆桌式的渲染逻辑与样式。
2. 工具栏保留行数、列数，并增加一个“走道”开关。
3. 走道开关开启时，在列数的正中位置插入竖向留白。例如 6 列显示为 3 列座位、走道、3 列座位；奇数列则在左半边较少的一侧之后插入走道。
4. 布局数据仅保存行数、列数和走道开关。读取旧存储数据时，忽略旧的布局类型和小组人数，按行列式渲染，避免页面错误。

## 范围

新增 `README.md`，并修改 `index.html`、`js/app.js` 和 `css/style.css` 中的布局界面与渲染实现；不变更本地依赖库。

## 验收标准

- README 首个可见章节明确表达免费、禁止商业用途和转载注明出处。
- 所有内容均为中文，描述与现有静态网页项目一致。
- 用户能通过单个走道开关在普通网格与中间走道网格之间切换。
- 已入座学生在调整行列或走道时保持原有顺序；关闭走道不会改变座位数量。
- 旧版保存的班级数据能在新版中正常打开。
- README 和布局改动被 Git 跟踪并推送到 `main`。
