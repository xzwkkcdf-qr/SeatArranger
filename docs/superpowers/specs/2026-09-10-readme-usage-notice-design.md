# README 使用声明设计

## 目标

为座位表编排工具新增中文 README，使使用者在打开仓库时首先看到使用限制：项目免费、不得用于商业用途，转载时必须注明原始出处。

## 文档结构

1. 使用与转载声明：置于 README 的第一项内容，使用醒目标题和三条明确规则。
2. 项目简介：说明这是一个本地运行的座位表编排工具。
3. 主要功能：概述名单导入、座位布局、排座与导出能力。
4. 使用方式：说明双击 `start.bat` 或用浏览器打开 `index.html`。
5. 项目结构：列出入口页面、样式、脚本及本地依赖库。

## 范围

仅新增 `README.md`，不修改应用代码、依赖或运行行为。

## 验收标准

- README 首个可见章节明确表达免费、禁止商业用途和转载注明出处。
- 所有内容均为中文，描述与现有静态网页项目一致。
- README 被 Git 跟踪并推送到 `main`。
